# CODSOFT - Basic Calculator

A sleek, functional basic calculator built using HTML, CSS, and JavaScript as part of the CODSOFT Web Development internship.

## 🚀 Features

- **Standard Operations**: Addition, subtraction, multiplication, and division.
- **Responsive Design**: Works seamlessly on both desktop and mobile devices.
- **Clean UI**: Modern and minimalist interface for an enhanced user experience.
- **Delete Functionality**: Easily correct mistakes with a dedicated DEL button.
- **Clear Display**: Quickly reset calculations with the 'C' button.

## 🛠️ Technology Stack

- **HTML5**: For the structural foundation.
- **CSS3**: For custom styling and responsive layout.
- **JavaScript (ES6+)**: For the core calculator logic.

## 📁 Project Structure

```text
├── index.html   # Main HTML structure
├── styles.css   # Custom CSS styling
├── script.js    # Calculator logic
└── README.md    # Project documentation
```

   ```bash
   git clone https://github.com/Dev-Anandhan/CODSOFT.git
   ```

   Simply open `index.html` in your preferred web browser.
